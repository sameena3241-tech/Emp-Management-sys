# Employee Management System

A web-based Employee Management System built using Python, Flask, Flask-SQLAlchemy, HTML, CSS, and SQLite.

The application allows users to add, view, update, and delete employee records through a web interface.

## 🚀 Features

- ✅ Add Employee
- ✅ View All Employees
- ✅ Update Employee Details
- ✅ Delete Employee
- ✅ SQLite Database Integration
- ✅ CRUD Operations
- ✅ Flash Messages
- ✅ Form Handling and Validation

## 🛠️ Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- Jinja2

## ⚙️ Installation & Setup

### 1. Clone the Repository
```
git clone <https://github.com/sameena3241-tech/Emp-Management-sys.git>
```

### 2. Navigate to the Project Folder

cd Emp-Management-sys

### 5. Install Dependencies

pip install -r requirements.txt

### 6. Run the Application
```
python Ems.py
```

### 7. Open in Browser

<http://localhost:5000/>

## 🖥️ Application Menu
The application features a clean navigation menu at the top:
* **HOME:** The main landing dashboard of the Employee Management System.
* **Employees:** Displays a table list of all current employees showing their ID, Name, Department, Salary, and Actions (Edit/Delete).
* **Add Employee:** A form layout to input and save new records to the database.

## 💡 Project Highlights

- Developed a web-based Employee Management System using Flask.
- Integrated SQLite database using Flask-SQLAlchemy.
- Implemented Create, Read, Update, and Delete (CRUD) operations.
- Used Jinja2 templates for dynamic HTML rendering.
- Implemented GET and POST methods for form handling.
- Added flash messages for user feedback.
- Used SQLAlchemy ORM for database operations.
